# 校准：红、绿、蓝原色色相

[English](calibration.md) · 简体中文

当参考需要改变整体色彩关系，且单靠白平衡或选择性的 HSL 调整不合适时，考虑校准。它调整红、绿、蓝原色，不等同于 HSL 中的红／绿／蓝颜色分组；混合颜色和肤色可能一起改变。以原生渲染判断效果，不把原色当作局部颜色选区。

先确定曝光、白平衡，并保留已有配置文件和处理版本。确有需要时，把适量的原色色相调整纳入首轮，再用 HSL 修正剩余局部色差。不使用固定配方、不强制移动蓝原色，也不额外增加“校准试色轮”。只有某个物体颜色不对时优先使用 HSL 或局部蒙版；不默认给每张照片加校准。

## 支持参数

| 校准控件 | 原生字段 | 绝对滑块范围 |
| --- | --- | --- |
| 红原色色相 | `RedHue` | -100 到 100 |
| 绿原色色相 | `GreenHue` | -100 到 100 |
| 蓝原色色相 | `BlueHue` | -100 到 100 |

数值是滑块单位，不是色相角度。`HueAdjustmentRed/Green/Blue` 仍是独立的 HSL 参数。本功能只读并保留三原色饱和度、阴影色调，同时保护配置文件和处理版本。校准面板关闭时停止写入，不悄悄启用已有调整。

[轮次执行器](rounds.zh-CN.md)语法示例，不是固定预设：

```json
{"action":"apply","settings":{"RedHue":12,"GreenHue":-8,"BlueHue":-15}}
```

只填写实际需要的参数。沿用已有 apply 路径，校验副本身份、新鲜旧值、范围、面板／配置文件／处理版本，保存快照并原生回读。导出前再独立核对三个请求值及校准上下文，与其他调整统一导出。已验收输出直接复用，不重复分析或渲染。

检查肤色、天空、植物、高饱和区域和中性色。天空变好而肤色受损，不能算匹配成功；在同一副本减弱或恢复原色色相。单张照片调整不修改相机默认值、预设或配置文件。

已在 Windows / Classic 13.0.2 的隔离 JPEG 虚拟副本上联合写入三个色相，完成独立回读、原生导出、全图及 100% 肤色检查。原文件哈希和母片设置不变，HSL、原色饱和度、阴影色调、配置文件、处理版本保持。验证的是控制行为，不是通用风格；RAW、其他版本仍需单独验收。已调色 JPEG 的零滑块不能撤销烘焙颜色。
