# Lightroom 应用工作流

[English](lightroom.md) · 简体中文

优先使用[桥接指南](bridge.zh-CN.md)中介绍的、经过验证的 Classic 集成。本文件涵盖桌面回退方案以及桥接之外的控件。执行前阅读当前桌面工具说明；不要使用固定坐标宏。

## Classic 桌面回退方案

1. 发现并确认实际的应用程序、窗口、目录和修改照片（Develop）模块。进程或窗口标题本身不足以证明已取得控制权：获取当前可读的 UI 状态。在任务授权范围内处理真实的登录、权限和目录对话框；不要仅为测试此技能而升级目录。
2. 准确定位请求的目标。尽可能复用目录对象；如需导入现有本地文件，通常使用“添加”（Add），仅导入指定文件。不要移动原始文件、扫描或同步整个文件夹，也不要更改云同步。参考图像可以保留在外部查看器中；导入参考图像并不代表获得编辑授权。
3. 确认只选中一个项目，并核查 Auto Sync（自动同步）状态。创建并识别一个命名的虚拟副本，该副本继承现有编辑。如果不可用，使用有文档记录的快照/版本回滚机制。默认绝不使用 Reset，也不要覆盖同名版本。
4. 记录副本/源文件身份、配置文件、处理版本、现有蒙版，以及与要修改的组相关的基线值。按照一致条件获取基线渲染结果。
5. 使用参考视图（Reference View）、前后对比，或可观察的并排比较。区分 Reference 与 Active：编辑作用于 Active。即使界面只提供一个参考槽位，也要查看所有参考图像。
6. 调整一个相关组，优先使用可编辑的数值。对于滑块，进行有界调整并读取结果。观察 → 目标 → 执行一次 → 刷新/验证，具体服从当前工具的交互规则。
7. 保留已检查的副本/快照，并在范围内导出。虚拟副本是目录中的编辑关系，并不是单独导出的图像。

## 控件与陷阱

| 目标 | 候选控件 | 检查项 |
| --- | --- | --- |
| 整体或主体亮度 | 曝光、白色/黑色、受支持的局部蒙版 | 目标照明效果，而不是照搬参考图像的曝光 |
| 黑位、对比度、高光过渡 | 色调曲线、对比度、高光/阴影 | 细节、当前曲线模式、通道以及实际是否支持输入控制点 |
| 光源颜色 | 色温/色调 | RAW 开尔文值与 RGB/JPEG 单位；绝不要假设它们使用相同的刻度 |
| 特定色相的强度或亮度 | HSL/颜色混合器 | 实际通道、调整方向以及伴随影响 |
| 影调的暖冷关系 | 阴影/中间调/高光颜色分级、混合/平衡 | 确认使用的是正确色轮还是亮度滑块；色相必须配合饱和度才会影响颜色 |
| 分离处理皮肤或天空 | 原生非生成式蒙版 | 选择边界和溢出；不得进行生成式内容替换 |

默认保留配置文件，因为它会改变整体色彩响应。如果任务需要更改配置文件，应在副本上测试并记录原因。只有在有参考证据且符合用户目标时，才添加颗粒或胶片模拟。

对于批量处理，先完成每种场景或光线下的代表图像。可复用预设可以传递已验证的颜色/影调设置，但曝光、白平衡和局部蒙版通常需要逐张调整。检查每张图像；如果同步影响了非预期设置，恢复到明确的回滚点。

仅在请求复用或确有需要时交付 XMP 预设。对于已验证的设置，优先使用 Lightroom 原生的 Create Preset/Export。写入 XMP 文件并不能证明它已经导入或应用。不要把预设与 RAW 旁车文件混淆，不得覆盖源旁车文件，也不得在没有明确意图的情况下，用磁盘元数据覆盖现有目录编辑。

导出到新的任务目录和文件名。本地审查通常使用 SDR sRGB 高质量 JPEG；如果请求 TIFF、位深、尺寸或其他格式，则必须通过受支持的控件予以满足。保留源 RAW 文件。重新打开导出文件并检查图像内容、尺寸、配置文件和预期外观。出现覆盖对话框时选择新名称。

## Lightroom 云端桌面版和其他应用程序

只有用户选择该产品时才使用此分支。不要假设 Classic 菜单、虚拟副本或 SDK 接口适用。检查实际版本以及 Local/Cloud 工作区。云端导入可能上传原始文件；本地调色请求本身并不授权上传，也不授权更改同步或隐私设置。

使用原生 Versions 或其他经过验证的回滚机制。观察/编辑/渲染循环仍然适用。如果本地控件或所需功能不存在，说明该限制；不要虚构远程 API，也不要默默替换软件。

Classic SDK 是可选的插件集成，并非预装的 MCP 服务。使用前确认已加载且获得授权的桥接及其当前能力。不要虚构 HTTP 端点、CLI 修改照片参数，或云产品支持。

如果 UI 读取失败，遵循工具规定的有界恢复流程。若反复失败，停止输入，保留分析，并报告应用程序工作未完成。能发现某个进程，并不能证明盲目键盘自动化安全或可用。

## 验证边界

插件管理器的 **运行只读连接检查**（Run read-only connection check）只生成诊断信息。接受最新且与请求匹配的新回执，并检查每项能力。启用状态、旧 JSON 文件或 SDK 方法存在，都不能证明编辑已成功。

Classic 13.0.2 曾有原生 JPEG 导入/复制/应用/回读/导出的验证记录。每个真实任务仍需要自己的参数回执和渲染检查。RAW 开尔文白平衡、其他版本、云产品以及桥接不支持的控件，都需要单独验收。

官方参考：[Adobe Lightroom Classic SDK](https://developer.adobe.com/lightroom-classic/)。已安装的控件和当前工具结果决定实际可执行的内容。

局部柔化参见[原生蒙版](masks.zh-CN.md)：命令模块 0.3.0，支持明亮度范围与过渡控制（Classic 13.0.2）、主体／天空／背景选区创建，或按精确已有蒙版 ID 调整；每张图仍须目视验收。
